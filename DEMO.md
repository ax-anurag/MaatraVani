# DEMO — the exact 5-minute script

Timings assume the demo laptop has the models downloaded
(`scripts/download_models.py` already run) and espeak-ng installed.
Every number the audience sees on screen is measured live by the app;
the reference table at the bottom was captured on the dev machine and is
regenerated by `scripts/offline_demo.py`.

Before the room: start the server once (`./scripts/run_dev.sh`), open
http://localhost:8000, allow microphone access. Keep a browser tab on
the system network settings to toggle Wi-Fi for Step 5.

---

## 0:00 — Set the scene (30 s)

> "This teacher speaks Hindi. Her students speak Santali. She doesn't.
> MaatraVani gives her three things: a voice translator, locally generated
> bilingual study material, and a way to pass information between devices
> with no internet. Everything runs on local models."

Point at the status pill: **ONLINE**. Mention: "the only reason we're
online right now is that you're watching a browser — the models are
already on this machine."

## 0:30 — Voice translation, Hindi to Santali (1 min 30 s)

1. Open **Voice Translator**. Language selector reads
   `[ Hindi ] -> [ Santali ]`.
2. Press the mic, say: **"बच्चों, आज हम जानवरों के नाम सीखेंगे।"**
3. Stop. The pipeline runs — one request, three local stages.
4. Show, top to bottom:
   * **Recognized Hindi** — the transcript;
   * **Santali — Ol Chiki** — the translation, real script, right there;
   * press **Play** — the class would *hear* Santali;
   * the **measured latency table** — read it out:
     "ASR X s, translation X s, TTS X s, total X s — measured just now,
     target under three seconds."
5. Note the badge: **LOCAL OFFLINE MODEL**, and the provenance line under
   the Santali card (verified lexicon entry vs machine translation with
   the review warning).

If asked about quality: "Machine translation is reviewed by the teacher —
that warning travels with every machine line, and our verified classroom
lexicon takes priority where we have verified entries."

## 2:00 — Kill the internet (1 min)

1. Turn off Wi-Fi / unplug the cable.
2. The pill flips to **OFFLINE - LOCAL MODELS ACTIVE**.
3. Say the same sentence again (or type it in text mode).
4. It still works. Same stages, same latency table, same audio.
5. > "Nothing called the cloud. If it had, you'd see it break — our
   offline test suite literally crashes the process on any network
   attempt."

## 3:00 — Study materials (1 min)

1. Open **Study Materials**. Pick Grade 2 / Foundational Literacy /
   topic **Animals** / the FLN outcome / Santali.
2. **Generate Lesson** — show the bilingual script: teacher line in
   Hindi, the same line in Ol Chiki, verified/machine badge per line,
   activity steps, assessment questions.
3. **Generate Worksheet PDF** — the printable bilingual matching sheet,
   rendered locally with proper text shaping for both scripts.
4. **Generate Flashcards** (4 cards) — the visual cards, emoji
   illustrations, no image API involved. Download the PDF if there's time.

## 4:00 — Offline mesh (1 min)

1. Open **Offline Mesh**. Read the banner out loud:
   **DEMO / SIMULATION MODE — no radio hardware involved.** Say:
   "We say this because browser Bluetooth on this box can't do a real
   radio demo, and we will not pretend otherwise."
2. Compose from **teacher**: *"कल गणित की कॉपी साथ लाईये।"*
   ("Tomorrow bring your mathematics notebook.")
3. Send. The timeline animates hop by hop: delivered to Student A
   (1 hop), relayed to Student B (**2 hops**). Duplicate suppressions and
   TTL are visible events, not claims.
4. Click **student B** — the inbox shows **"Received via mesh - 2 hops"**
   with the path `teacher -> student-a -> student-b`.
5. Close: "Same message format, same TTL and duplicate rules as the real
   BLE transport — the simulation swaps out behind one interface."

## If something fails live

* **mic denied / no mic** — use text mode; same chain, same latency table
  minus ASR.
* **TTS missing** — the app itself will say "Santali TTS model
  unavailable"; that means espeak-ng (with its Hindi voice, which carries
  the Santali transliteration) is not installed
  (`scripts/install_espeak_nosudo.sh`). Say that;
  don't narrate around it.
* **API budget** — the app caps itself at 25 requests/min on purpose;
  a 429 means the demo hit its own guard rail, which is the design
  working. Wait a minute and continue.
